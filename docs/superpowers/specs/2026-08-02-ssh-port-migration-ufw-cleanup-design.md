# SSH 端口迁移 UFW 清理修复设计

## 目标

修复完成 SSH 端口迁移时，UFW 的 IPv4/IPv6 多行展示或旧规则已不存在导致的误报；保证失败提示与实际变更一致。

## 规则边界

- 仅管理状态文件中记录的 `security-manager-ssh-old-<port>` 完整备注。
- 使用端口、TCP 协议和完整备注删除一条 UFW 逻辑规则；IPv4/IPv6 展示行由 UFW 一并处理。
- 旧备注不存在时视为幂等成功。
- 相同端口但备注不同的 `managed-inbound`、`SSH-<port>`、TCP/UDP 规则均不处理。

## 失败处理

- SSH 写入前完成 UFW 可读性和旧规则状态检查。
- SSH 配置写入或重载失败时恢复文件及原监听状态。
- SSH 已切换后 UFW 清理失败时恢复 SSH 文件及原监听状态；回滚成功返回“应用失败，已验证回滚”，回滚失败返回保护级错误。
- 不再把已发生变更的失败归类为“前置检查失败，未执行任何变更”。

## 验证

- 覆盖旧规则不存在、IPv4/IPv6 多行展示、精确备注隔离、UFW 删除失败回滚及返回码。
- 运行现有自测和事务测试，确保转发管理不受影响。
